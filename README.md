# 너굴라이언트

너굴마을(mcng.kr, 마인크래프트 26.1.2 Fabric) 전용 런처. Nova Client 의 로그인·실행·Fabric·servers.dat 코드를 가져와 만들었어요.

## 유저에게 줄 것 = 설치 파일 하나

`dist\Nugulient-Setup.exe` 하나만 주면 돼요. 유저는 이걸 실행만 하면 끝이에요.
(자바 · Fabric · 마인크래프트 파일은 처음 PLAY 할 때 런처가 알아서 받아요)

### 설치 파일 만들기 (이 폴더에서, 처음 한 번만 Node.js 설치 필요)

```
npm install        # 처음 한 번
npm run dist:win   # → dist\Nugulient-Setup.exe
```

- 만들기 직전에 너굴마을 로고를 받아서 앱 아이콘으로 넣어요 (`scripts/make-icon.js`, 인터넷 필요)
- 개발 중 화면만 볼 땐 `npm start` (데이터: `%APPDATA%\Nugulient-Dev`)

### 나눠 주는 방법

- **GitHub Releases 추천** - 설치 파일이 80MB 정도라 디스코드에 직접 못 올리고, 여기에 올려야 자동 업데이트도 돼요. 릴리스 페이지 링크를 공지에 올리면 끝
- 처음 실행하면 윈도우가 "Windows의 PC 보호" 창을 띄울 수 있어요 (코드 서명 인증서가 없어서). 유저에게 **추가 정보 → 실행** 을 누르라고 안내해 주세요

## 자동 업데이트 · 릴리스 올리기

GitHub 저장소 **Sil2ntium7012/nugulient** 의 Releases 로 배포 · 업데이트해요.

1. https://github.com/Sil2ntium7012/nugulient/actions → **Build Nugulient** → **Run workflow** → **Run workflow**
2. 버전은 알아서 올라가요 (처음 1.0.0, 그다음 1.0.1, 1.0.2 …) — package.json 에도 자동 저장
3. 몇 분 뒤 Releases 에 `Nugulient-Setup.exe` · `latest.yml` 이 올라감
4. 이미 설치한 사람은 런처가 새 버전을 받아서, 마크가 꺼져 있으면 바로 알아서 완전히 종료 → 설치 → 다시 실행 (마크 중이면 게임을 끈 직후에)

main 에 코드만 올리면(push) 테스트용 설치 파일만 Actions > Artifacts 에 생기고 배포는 안 돼요.

## 기능

- **PLAY** → 자바 25 · Fabric 자동 준비 후 무조건 mcng.kr 로 접속
  - 홈 PLAY 위에서 메모리 바로 변경 (설정 > 게임과 같은 값)
  - 실행할 때마다 자동으로 넣는 것: 내 클라이언트 모드(Luna's Light, `novamod/builtin-mod-26.1.2-*.jar`), 너굴마을 모드체커(접속 필수, mcng.kr 에서 하루 한 번 확인), Fabric API
  - 모드 처음 설정을 아직 안 한 PC 는 설정을 마친 뒤 너굴마을로 들어감 (노바클과 같음)
  - 모드에 넘기는 값(`.luna-launch.json`): 너굴마을 전용 인게임 테마(`cosmetics.theme.mode = "neogul"` + 나무/크림/초록 palette, 런처 테마와 무관), 재접속 끄기(`features.relogin = false`)
    → **모드(Luna's Light) 쪽에서 이 값을 읽도록 만들어야 실제로 적용돼요**, 멀티 목록 맨 위에 "너굴마을"
- **계정**: 마크 계정은 1개만. 저장된 계정 → 노바클 로그인 기록 → 마이크로소프트 로그인 순으로 자동 로그인
- **모드**
  - 추천 탭: 맨 위에 너굴마을 기본 모드(너굴 로고 아이콘, "기본 모드 모두 설치"), 그 아래 **망고's pick** (모드 42 · 리소스팩 5 · 쉐이더 3, 종류별 "모두 설치")
  - 망고's pick = 노바 클라이언트 "너굴마을" 프로필에 넣어 쓰던 구성 그대로 (`catalog.js` 의 `MANGO_PICKS`)
  - 모드 · 리소스팩 · 쉐이더 탭: 검색어가 없으면 맨 위에 기본 모드 · 망고's pick 고정, 검색 결과 · 설치됨 목록에도 망고's pick 태그
  - Modrinth 검색 · 원클릭 설치(필수 의존 모드 포함) · 리소스팩/쉐이더 바로 적용
- **스킨**: 3D 미리보기, 스킨 변경, 최근 스킨
- **보관함**
  - 이번 주 뽑기: 한국 시간 월요일 0시마다 1회. 색상(일반 24 · 레어 3)과 테마(에픽 4 · 레전더리 5) 중 하나
  - 내 보관함: 얻은 테마 · 색상 장착
  - 도감: 전체 37종 채우기 (안 얻은 건 ??? 로 표시)
  - 노바클에서 가져오기: 노바클 보관함(같은 마크 계정)에 있는 색상 · 테마를 그대로 가져옴 (첫 로그인 때 자동)
- **설정 > 화면**: 기본 바탕(그레이/화이트), 포인트 색, 폰트, 글자 크기
- **질문 (너굴 도우미)**: 너굴마을 위키(/wiki)·규칙(/rules)을 받아 PC에 저장해 두고(12시간마다 새로), 질문과 맞는 항목을 찾아 관련 줄만 골라 답해요. 서버·API 키 없이 동작
  - "디코인증 어떻게 해?"처럼 방법을 물으면 단계별로, "/섬 초대"처럼 명령어를 치면 명령어 표에서 바로
  - 요리 이름 + 가격/시세를 물으면 오늘 시세(그릇별 포인트·내일 예상)로 답하고 계산기로 연결
  - 검색 규칙(동의어·불용어·질문 종류별 가중치)은 `src/ask-engine.js`
- **계산기**: Nova Calculator 와 같은 계산기(시세 · 무역 · 요리 최적화)를 `src/calc` 에 넣고 iframe 으로 띄움. 색은 런처 테마를 그대로 따라감
  - 요리 시세는 매일 00:30(한국 시간)에 받아와요 (`%APPDATA%\Nugulient\tools`)
- **홈 아래**: 추천하고 보상 받기(마인리스트 추천 버튼, 오늘 추천했는지 표시 - 자정 초기화, 저녁 8시 핫타임까지 남은 시간, 보상 목록) + 위키 바로가기(자주 찾는 항목 · 디스코드 · 커뮤니티 · 규칙 · 후원). 사이드바 위키 탭은 없앰
- **기능** (예전 계산기 탭): 요리 시세 · 무역 계산기 · 요리 최적화(계산기 해당 화면으로 바로), 너굴 도우미, 랭킹, 스크린샷 모아 보기, 리소스팩 깨짐 해결(downloads 폴더 비우기), 로그 · 게임 폴더 열기

## 고칠 곳

- 서버 주소 · 위키 링크 · 전용 모드 주소 → `catalog.js`
- 뽑기 확률 · 색상/테마 목록 → `src/cosmetics.js` (id 는 노바클 상점과 같게 맞춰 둠)
- 사이트 이미지(로고 · 섬 전경)는 너굴마을 운영진 허락(비상업적)을 받아 사용. 하루 한 번 받아서 PC 에 저장해 둠 (`catalog.js` 의 `IMAGES`)
- 앱 아이콘(`build/icon.png`, `icon.ico`)은 임시 너구리 아이콘

## 너굴마을 정보 자동 갱신 (2시간마다 + 켤 때 + PC 가 잠에서 깰 때)

- **랭킹**: `https://mcng.kr/data/rankings.json` → 랭킹 탭 (레벨 · 인기도 · 섬 · 돈 · 낚시 · 무역 · 플레이타임 · 질문 채택 · 최초 달성). 내 닉네임이 있으면 강조
- **전용 모드 최신 파일**: 위키의 `/mods/...` 링크를 읽어서 파일 이름(버전)이 바뀌었으면 설치 주소를 자동으로 바꿈 (예: ng-koreanchat-2.1.4 → 2.1.5)
- **사이트 이미지**: 로고 · 섬 전경 (하루 한 번)

## 저장 파일 보호

- 계정 · 보관함 · 뽑기 기록은 `config.json` 이 아니라 `secure.dat` 에 **AES-256-GCM 으로 암호화**해서 저장
- 열쇠는 설치할 때 무작위로 만들고 윈도우 계정 보호(DPAPI)로 감싸 둠 → 메모장으로 열어도 내용이 안 보이고, 다른 PC 로 복사해도 안 열림
- 한 글자라도 고치면 열리지 않아서, 고친 흔적이 있으면 보관함과 로그인 정보를 초기화하고 알림을 띄움 (원본은 `secure.dat.broken-…` 으로 남김)
- 뽑기는 PC 시계가 아니라 인터넷 시각으로 판단 → PC 날짜를 바꿔서 다시 뽑을 수 없음 (인터넷 연결 필요)
- 예전 버전이 `config.json` 에 평문으로 남긴 계정 · 보관함은 처음 켤 때 자동으로 옮기고 지움
